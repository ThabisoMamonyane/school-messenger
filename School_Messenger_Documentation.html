1. Product Overview

School Messenger is a secure mobile communication platform designed to bridge the gap between schools, parents, and staff. The app provides a centralized hub for school announcements, group messaging, and institutional communication.

System Architecture Overview

Key Value Propositions

For Schools

  • ✅ Centralized communication platform
  • ✅ Staff & group management
  • ✅ Broadcast announcements
  • ✅ Category-based messaging
  • ✅ Analytics & read tracking

For Parents

  • ✅ Real-time access to school updates
  • ✅ Easy school discovery & joining
  • ✅ Push notification alerts
  • ✅ Multi-school support
  • ✅ Secure, reliable messaging

2. Vision & Goals

Primary Goals

  1. Improve School-Parent Communication - Create direct, reliable channels between educational institutions and families
  2. Centralized Announcements - Single source of truth for school news, events, and updates
  3. Global Accessibility - Allow parents worldwide to connect with schools
  4. Secure Authentication - Role-based access with verified accounts
  5. Tiered Service Model - Support free and premium subscription tiers

8. API & Backend Services

Supabase Configuration

export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
    auth: {
        storage: AsyncStorage,
        autoRefreshToken: true,
        persistSession: true,
    },
});

Real-time Subscription

supabase.channel(`group_chat:${groupId}`)
    .on('postgres_changes', {
        event: 'INSERT',
        table: 'messages',
        filter: `group_id=eq.${groupId}`,
    }, handleNewMessage)
    .subscribe();

10. Security Considerations

  • ✅ Passwords hashed via Supabase Auth (bcrypt)
  • ✅ JWT-based session management
  • ✅ Row Level Security (RLS) on all tables
  • ✅ HTTPS for all API calls
  • ✅ File size limits (10MB for attachments)
⚠️ Recommendations: Implement server-side RLS policies, add rate limiting, conduct security audit before production.
