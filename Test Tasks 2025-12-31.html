🚀 Production Test Plan

A Comprehensive A-Z Checklist for Soft Launch Readiness
Pre-Requisites: Ensure you have the Web Portal running on your desktop and the Mobile App installed on a physical device (or simulator). create two test accounts: one Admin User and one Parent User.

Phase 1: Authentication & Onboarding

New User Sign Up Critical Register a new account via the Mobile App. Verify success message and automatic login.
Email Validation (If enabled) Check if email verification link arrives and works (if configured in Supabase).
Logout Functionality Log out from the Profile screen. Ensure user is returned to Welcome/Login screen.
Login (Existing User) Log back in with the newly created credentials. Verify quick access.
Forgot Password Flow Request a password reset. Verify email arrival and deeplink opening the reset screen.

Phase 2: Mobile App Experience

Feed Scrolling & Performance Scroll rapidly through the Announcements feed. Ensure no lag or visual glitches.
View Announcement Details Tap an announcement. Ensure it expands or opens detail view correctly.
Attachment Handling Critical Find an announcement with a Paperclip icon. Tap it. Verify the attachment opens/downloads.
Tab Navigation Transition Switch between Home, Dashboard, and Profile tabs. Verify the "Slide Left" animation works smoothly.
Join a School (Parent Role) Use "Find Schools" to search and join a new school. Verify it appears in "My Schools".

Phase 3: Web Portal (Admin)

Dashboard Stats Load Login as Admin. Verify "Unread Announcements" and "Total Students" stats load without error.
Create Announcement (Text Only) Critical Post a simple text announcement. Verify "Success" toast.
Create Announcement (With Attachment) Create a post and upload a PDF/Image. Verify upload progress and final submission.
Manage Staff Navigate to Staff page. Attempt to Invite a new teacher by email.
School Profile Update Edit school address or phone number. Save. Verify changes persist.

Phase 4: Real-time & Cross-Platform

End-to-End Broadcast Critical 1. Open Mobile App (keep open).
2. On Web, post a new announcement.
3. Verify Mobile App updates automatically without refreshing.
Push Notification Delivery Close the Mobile App (background). Post from Web. Verify Push Notification arrives on device.
Deep Link from Push Tap the received notification. Verify App opens directly to the announcement.
